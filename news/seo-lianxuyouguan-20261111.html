不锈钢连续油管标准规范解读与钢级壁厚选型指南

更新日期：2026-11-11分类：行业标准

不锈钢连续油管（Coiled Tubing，业内常称 CT 或挠性油管）是油气井作业中的核心连续管材，以整盘无接头的形式一次性下入井内，广泛用于冲砂、钻磨、酸化、测井、完井等作业。面对市场上从 CT55 到 CT120 的不同钢级、不同壁厚的产品，采购和工程人员常常困惑：连续油管到底执行哪些标准？钢级怎么选？壁厚如何匹配井况？本文围绕不锈钢连续油管相关的 API 5ST、API RP 5C7 等标准规范，结合钢级力学性能、壁厚公差与缺陷验收要求，给出一套可直接落地的选型与验收方法，帮助你把技术协议写清楚、把风险控在前端。更完整的产品规格参数可参考不锈钢连续油管产品页。

一、连续油管标准体系：从 API 5ST 到国内标准

连续油管的制造、检验与作业都有成体系的标准支撑，理解这套标准体系是选型和写技术协议的前提。订货与验收通常以产品规范为主，辅以作业与检验推荐做法，出口项目还要兼顾国际标准。

标准类型核心内容
API 5ST产品规范连续油管的尺寸、钢级、制造、检验与缺陷验收的统一规范，是采购订货的主标准。
API RP 5C7作业推荐做法连续油管下入、起出、循环、疲劳管理等现场作业的技术建议。
API RP 5C6修复与整修使用中连续油管的检查、修复、降级与报废判据。
API RP 5C8检验规范连续油管在线与离线检验的方法、设备与判伤准则。
ISO 13636国际标准与 API 5ST 协调的国际连续油管规范，便于出口与多国项目互认。
SY/T 5325、SY/T 6128国内行标国内石油天然气行业对连续油管作业与检验的配套要求。

在订货单和技术协议里，通常以 API 5ST 为产品验收依据，辅以 API RP 5C7/5C8 的作业与检验要求；出口项目则常需兼顾 ISO 13636。对不锈钢连续油管而言，还需叠加耐腐蚀材质（如 316L、双相钢、镍基合金）对应的材料标准。

二、钢级（CT 钢级）是什么意思：CT55–CT120 力学性能对照

钢级（Grade）代表连续油管的强度等级，数字越大屈服强度越高。选钢级本质是选“够用且留余量”的强度，而不是越高越好。

钢级最小屈服强度 (ksi)最小屈服强度 (MPa)典型应用倾向
CT7070483浅井、轻负荷冲砂与循环
CT8080552常规修井、钻磨、酸化主力
CT9090621中深井、较高作业压力
CT100100689深井、大负荷与高抗拉需求
CT110110758深井、长水平段、重负荷工况
CT120120827极限深井与高抗拉作业

抗拉强度一般约为最小屈服强度的 1.1–1.25 倍，具体数值以 API 5ST 对应钢级规定为准。需要提醒的是，钢级越高，管材硬度与残余应力往往越大，在含硫环境下需同步核对 NACE MR0175/ISO 15156 的硬度上限要求。

选型时不必盲目追高钢级：钢级只解决强度，耐蚀性由材质决定。含硫、含氯的油气井应优先确认材质（316L、2205、2507 或镍基）与硬度限制，而不是单纯提高钢级。

三、外径与壁厚规格：常用尺寸与制造公差

连续油管的外径决定可下入的井眼与工具串尺寸，壁厚决定承压与抗挤能力。两者需一起选，不能只看其一。

上表为行业常见组合，实际以 API 5ST 标称值为准。标准对壁厚公差通常不允许负偏差（实际壁厚不得低于标称值），并对最大外径、椭圆度、直度等几何尺寸设定上偏差；订货时应明确“壁厚只允许正偏差”或“最小剩余壁厚”要求，避免到货壁厚偏薄。

壁厚每增加 0.2 mm，抗内压与抗挤能力都有明显提升，但也会增大单位长度重量、降低盘长与起下速度。因此壁厚不是越厚越好，而是按最大作业压力加安全系数反向推算最经济值。

四、壁厚选型与抗压溃：怎么按井况定壁厚

壁厚选型要同时满足抗内压和抗外挤（抗压溃）两个方向，还要留足安全系数。

抗内压可用简化的 Barlow 公式估算：P = 2·S·t / (D − t)，其中 P 为爆破压力，S 为许用应力（取屈服的一部分），t 为壁厚，D 为外径。抗压溃则相反，由外压与管体椭圆度、残余应力共同决定，壁厚越薄、外径越大越容易压溃。工程上一般取作业最大压力的 1.5–2 倍作为设计压力，再据此选壁厚。

以 1.5″（38.1 mm）外径、壁厚 2.8 mm 的 CT80 为例：其抗内压能力可覆盖多数常规修井与酸化压力；若井深大、环空存在高外挤，则需上移壁厚或钢级。具体数值建议由供应商按 API 5ST 公式核算，并在技术协议里附计算书。连续油管在井下作业中的具体选型与检查清单，可参见不锈钢连续油管井下作业应用与工况参数指南。

这里不锈钢连续油管的“连续无接头”优势就体现出来了：整盘管柱没有接箍薄弱点，抗内压与抗挤的一致性远好于逐根接箍的常规油管，这也是它能在高压作业中被大量使用的原因。

五、缺陷验收与剩余壁厚：标准允许什么、禁止什么

连续油管在下入、起出和作业中会反复弯曲，表面与壁厚是验收重点。API 5ST 与 API RP 5C8 对可接受的缺陷有明确判据。

缺陷类型允许判据（示意，具体以订货标准为准）处理要求
表面划伤/凹坑深度 ≤ 壁厚的 12.5% 且不超过规定绝对值记录位置，不超剩余壁厚即可接受
鼓包/褶皱不允许判废或切除
椭圆度不超过外径规定上偏差超差段切除
壁厚减薄最低剩余壁厚 ≥ API 5ST 规定值低于下限判废
裂纹不允许判废或切除

验收时不要只看“有没有缺陷”，更要看“剩余壁厚是否在下限之上”。连续油管是疲劳件，每一次盘卷和注入头弯曲都消耗壁厚安全裕度，因此剩余壁厚比单点缺陷更关键。

建议到货与每口井作业后都用 API RP 5C8 规定的探伤方法复核壁厚，建立单盘管的“壁厚—循环次数”台账，超过剩余壁厚下限的管段及时切除或降级。

六、疲劳寿命与循环次数：API RP 5C7 怎么算

连续油管不是按“用了多少年”算寿命，而是按“经历了多少次弯曲循环”算。盘卷进注入头、再从鹅颈弯进入井内，这一进一出就是若干次循环。

影响疲劳寿命的核心因素有三个：弯曲半径（鹅颈与滚筒半径越小，疲劳越快）、管壁应力（压力越高、壁厚越薄应力越大）、累计循环次数。API RP 5C7 提供了基于应力幅值与循环次数的疲劳估算方法，供应商一般会给出该规格在给定弯曲半径下的参考循环寿命。

因素对疲劳寿命的影响
弯曲半径增大寿命显著延长
作业压力升高寿命缩短
壁厚增加寿命延长
循环频繁（注入头速度高）累计消耗加快

工程上常用“剩余循环次数”管理寿命：每次作业记录下入深度、压力与循环数，对照出厂疲劳曲线扣减，剩余不足时提前更换管段。把疲劳当台账管，比凭经验估更可靠。

七、制造、检验与材质证明：出厂必带的文件

采购不锈钢连续油管，文件与管材同样重要，尤其是用于出口或含硫井时。

随货应至少具备：材质证明书（按 EN 10204 3.1 或同等）、化学成分与力学性能检测报告、壁厚与几何尺寸检验记录、无损探伤（涡流/超声）报告，以及符合 API 5ST 的标识。使用 316L、双相钢、镍基等耐蚀材质时，还应要求提供腐蚀试验或材质溯源文件。

到货验收时，建议对照技术协议逐条核对：钢级、外径、壁厚、长度、剩余壁厚下限、表面状态、追溯编号，并抽查封样。相关到货检验清单可参考我们整理的不锈钢连续油管验收与作业前检查清单。

八、采购技术协议：必写的 8 项标准条款

把标准落到纸面，最稳妥的方式是在技术协议里写清以下条款，避免到货扯皮。

  1. 执行标准：明确 API 5ST（主）＋ API RP 5C7/5C8（作业与检验），出口加 ISO 13636。
  2. 钢级与材质：写明 CT 钢级、母材牌号（316L/2205/2507/镍基）及硬度上限。
  3. 尺寸与公差：外径、壁厚、长度，壁厚只允许正偏差或规定最小剩余壁厚。
  4. 力学性能：最小屈服/抗拉及延伸率要求。
  5. 无损与缺陷验收：引用 API 5ST/5C8 的缺陷判据与剩余壁厚下限。
  6. 追溯与标识：管体喷标、炉批号、材质证明编号一致可查。
  7. 文件交付：材质证明、检测报告、探伤记录、疲劳曲线清单。
  8. 包装运输：盘卷固定、端头封堵、防潮防撞与吊装要求。

把上述条款写进协议，供应商报价和交货就有了统一基准，后续验收也有据可依。需要模板可参考不锈钢连续油管采购选型与规格书编制指南。

九、常见标准误区

  • 误区一：钢级越高越好——错，耐蚀看材质，高强度钢在含硫环境可能受硬度限制。
  • 误区二：只看外径不看壁厚——错，壁厚决定承压与抗挤，是安全核心。
  • 误区三：负公差无所谓——错，壁厚负偏差会直接削减安全裕度，标准通常不允许。
  • 误区四：疲劳是年限问题——错，疲劳按弯曲循环次数计，台账管理才科学。
  • 误区五：国产不符合 API——错，合规国产连续油管同样按 API 5ST 生产并出具材质证明，关键看厂家资质与第三方检验。

不锈钢连续油管标准规范常见问题

CT80 和 CT90 差在哪？

两者最小屈服强度分别为 552 MPa 与 621 MPa，CT90 适合更深、负荷更高的井。但仅差钢级解决不了耐蚀问题，含硫井仍要看材质与硬度。

连续油管能用多少次、多少循环？

没有固定年限，按弯曲循环次数管理。具体循环寿命由规格、弯曲半径与压力决定，以厂家疲劳曲线为准；现场用剩余壁厚台账控制。

壁厚公差允许负偏差吗？

API 5ST 通常不允许壁厚负偏差，要求实际壁厚不低于标称值，并对几何尺寸设上偏差。订货时应明文规定最小剩余壁厚。

国产连续油管符合 API 5ST 吗？

合规厂家按 API 5ST 生产并出具材质证明与检验记录，与进口管执行同一规范；采购时核验厂家资质、第三方检验与追溯文件即可，不必迷信进口。

连续油管能修复再用吗？

可以。API RP 5C6 规定了检查、修复、降级与报废判据；对局部缺陷管段可切除重焊或降级使用，但修复后须重新检验并记录。

选钢级主要看什么参数？

主要看最大作业压力、井深、抗拉需求与含硫/含氯环境。先用压力反算壁厚与钢级，再核对材质耐蚀与硬度限制；兼顾经济性与安全余量。
